ÉTAPE 1: Ouvrir n8n
-------------------
Allez sur: http://localhost:5678


ÉTAPE 2: Créer un nouveau workflow
-----------------------------------
Cliquez sur le bouton [+] "Add workflow" en haut


ÉTAPE 3: Importer le fichier
-----------------------------
1. Cliquez sur les 3 points [...] en haut à droite
2. Sélectionnez "Import from File"
3. Naviguez vers ce fichier:
   
   n8n/workflow_finance_mlflow_ultra_simple.json
   
4. Cliquez "Open"


ÉTAPE 4: Sauvegarder et Exécuter
---------------------------------
1. Cliquez sur "Save" (en haut à droite)
2. Cliquez sur "Execute Workflow" (bouton en haut)
3. Attendez que tous les nœuds deviennent verts ✅

Vous devriez voir:
  ✅ [Manual Trigger] - Vert
  ✅ [Login] - Vert
  ✅ [Price Prediction] - Vert
  ✅ [Log to MLflow] - Vert


ÉTAPE 5: Vérifier dans MLflow
------------------------------
1. Allez sur: http://localhost:5000
2. Cliquez sur: "n8n_Finance_Pipeline"
3. Cliquez sur l'onglet: "Table" (PAS "Overview")
4. Vous verrez le run avec les métriques! 🎉
