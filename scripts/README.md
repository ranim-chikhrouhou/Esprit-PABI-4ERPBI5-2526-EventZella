# Scripts

Run these from the **repository root** (`PI BI NEW`), not from this folder.

```powershell
cd "path\to\PI BI NEW"
python scripts/build_dashboards_table2_with_formulas.py
python scripts/build_dashboards_table2_dax_et_visuels.py
python scripts/build_eventzilla_dashboards_html.py
.\scripts\convert_EventZilla_doc_to_pdf.ps1
```

Output paths are under `deliverables/` and `docs/eventzilla/` (see each script header).
